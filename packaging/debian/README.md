# Debian / Ubuntu packaging

`build-deb.sh` builds a `.deb` of CookCLI from a checkout: the `cook` binary,
bash/zsh/fish completions generated by it, the copyright file and the README.
It uses plain `dpkg-deb` — there is no `debian/` source package — and lets
`dpkg-shlibdeps` compute `Depends:` from the binary. With rustls for TLS and
SQLite compiled in, that comes down to `libc6` and `libgcc-s1`.

## How the package is built

The binary is built with `--no-default-features --features
server,import,lsp,sync`, as for the RPM:

- **`self-update` is disabled on purpose.** A packaged binary must not replace
  itself from GitHub releases — the package manager owns the file. `cook
  update` is therefore absent; users update with `apt`.
- **Build on the oldest distribution you support.** The binary needs a glibc
  at least as new as the one it was built against. CI builds on
  `ubuntu:22.04` (glibc 2.35), so the package installs on Ubuntu 22.04+ and
  Debian 12+.
- **Rust comes from rustup**, not from the distribution: Ubuntu's and
  Debian's own `rustc` are too old for this crate.

The version comes from `Cargo.toml`. Set `DEB_REVISION` (default `1`) for a
rebuild of the same version, and `DEB_MAINTAINER` to fill the `Maintainer:`
field (default: the project's issue tracker).

## Building locally

Inside an Ubuntu 22.04 container, from the repository root:

```bash
npm ci && npm run build-css && npm run build-js   # once, for the web assets
docker run --rm -it -v "$PWD:/src" -w /src ubuntu:22.04 bash -c '
  apt-get update && apt-get install -y build-essential dpkg-dev curl &&
  curl -sSf https://sh.rustup.rs | sh -s -- -y --profile minimal &&
  . "$HOME/.cargo/env" && ./packaging/debian/build-deb.sh'
```

The package lands in `dist/deb/`.

## CI

- `.github/workflows/deb.yaml` builds the packages on demand (manual dispatch,
  or on changes to this directory), then installs each on Debian 12, Debian 13,
  Ubuntu 22.04 and Ubuntu 24.04 and runs it.
- The release workflow builds them the same way for every GitHub release and
  attaches them to the release, next to the tarballs and RPMs.
